Support-verified forwarding proof

The only way a customer is shown Protected until automatic verification exists. Every action is checked by the database and recorded permanently in the audit.

Procedure (attended, customer on the line)

  1. The customer confirms call forwarding is switched on, using the code or Settings path the app showed them.
  2. From a designated support phone, dial the customer's own mobile number. Never the HCG number.
  3. The call must arrive in the HCG app and the customer must answer it in the app. Then end the call.
  4. Load the household below and pick that call. Enter the last 4 digits of the mobile number you dialled, write a reason, type the confirmation, and record.
